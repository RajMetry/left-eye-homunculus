# Changelog

Notable changes to LEFT EYE are documented here.

## 1.0.0 — Initial public prototype package

- Added the dual Right Eye / Left Eye visual modes.
- Added a Three.js body-metaphor figure, local keyword mapping, region overrides, and three demo presets.
- Added manual camera Cover Test and optional on-device-only speech recognition.
- Added printable exploratory reports with non-diagnostic disclaimers.
- Removed AI-provider integration and API-key handling from the public release.
- Added CSP/referrer protections, input validation, static release tests, and GitHub Pages workflow.
- Documented limitations and the remaining third-party CDN trade-off.
