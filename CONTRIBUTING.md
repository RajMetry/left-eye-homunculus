# Contributing to LEFT EYE

Thanks for helping improve LEFT EYE. Contributions should keep the project exploratory, transparent, and respectful of user privacy.

## Before opening a PR

- Run `npm test` with a current Node.js release.
- Describe what changed and how it was tested.
- For UI changes, include before/after screenshots if you have a real-browser capture. Do not claim a browser test was run if it was not.
- Keep the static app API-free unless a future design explicitly documents a reviewed privacy/security change.
- Keep clinical language non-diagnostic and avoid treating metaphors or scores as evidence of trauma or a health condition.

## Do not include

- API keys, passwords, access tokens, `.env` files, or private configuration.
- Real patient information, diagnoses, health records, voice recordings, or personal identifiers.
- Unlicensed images, fonts, or other assets.

## Pull requests

Prefer small focused changes. Explain the user benefit, outline the test steps, note known limitations, and update the README or `TEST_REPORT.md` when behaviour or setup instructions change.
